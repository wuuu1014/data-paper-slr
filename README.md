# Data Paper Systematic Literature Review

This repository contains the structured data, appraisal records,
reviewer-agreement audit materials, analysis code, and reproducible
outputs for a systematic literature review of data papers and
associated research-data evaluation.

## Repository structure

- `data/`: Final analysis datasets and audit files
- `code/`: R/Quarto analysis scripts
- `output/tables/`: Tables generated by the analysis
- `output/figures/`: Figures generated by the analysis

## Main datasets

- `SLR_112_Data_Extraction_and_Synthesis.xlsx`
- `EBL_Critical_Appraisal_Scores.xlsx`
- `Excluded_Studies_with_Reasons.xlsx`
- `Coding_Table.xlsx`
- `Reviewer_Agreement_and_Adjudication_Audit.xlsx`

## Reproducing the analysis

1. Download or clone this repository.
2. Open `SLR_Data_Papers_Project.Rproj` in RStudio.
3. Install the required R packages.
4. Run the files in the `code/` directory in numerical order.
5. Generated tables and figures will be saved in `output/`.

## Software

The analysis was conducted using R and Quarto.
